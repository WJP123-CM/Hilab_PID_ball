# 控制与调参

> 球杆系统看起来像一个普通的双环 PID 问题，真正难的是**静摩擦、传动回差和执行器加速度上限**。
> 本文按"控制律 → 机械现实 → 调参方法"的顺序展开，参数值刻意不写——它们只对某一套机械有效。

## 1. 被控对象

球在倾角为 θ 的管内纯滚动，忽略滚动阻力时：

```text
a = (5/7)·g·sinθ        （实心球，纯滚动）
```

对控制而言可以记成两句话：

- **角度决定加速度，加速度积分成速度，速度积分成位置**——θ → x 是双积分环节，开环不稳定，必须闭环。
- 小角度近似下 `a ∝ θ`，所以"控制位置"本质上是在"调度加速度"。

机械链是：电机轴 → 法兰联轴器 1:1 → 摆杆枢轴 → 管子倾角。这条链上串着三样东西：**回差、静摩擦、有限的角行程**。它们决定了性能上限。

## 2. 串级结构与各环职责

| 环 | 输入 | 输出 | 频率 | 主要职责 |
|---|---|---|---|---|
| 外环 | 球位置误差 | 摆杆角度增量（counts） | 10Hz | 决定"该倾多少"，处理静摩擦与死区 |
| 内环 | 角度误差 | 脉冲频率（Hz，带符号） | 50Hz | 让电机真正到达该角度，处理换向与失步 |

外环只做"慢决策"，内环把电机与传动的非线性收进快速环。两级之间只传一个角度指令，互不感知对方的实现。

## 3. 外环

### 3.1 PD 是基础，I 不是默认项

```text
u = Kp·e + Kd·de/dt
```

- 外环对象近似双积分，PD 提供阻尼，足以稳定。
- 加 I 会引入 −90° 相位。本来相位裕度就有限（采样延迟 + 滤波滞后 + 传动回差），加 I 后实测直接变成周期约 4~5 秒的极限环。
- 需要积分时，不要直接开 `Ki`，用后面的**条件积分**。

### 3.2 D 项的速度从哪来

两种来源，只能选一个：

| 来源 | 优点 | 缺点 |
|---|---|---|
| 误差差分 `e[k]−e[k−1]` | 无额外滞后 | 把位置噪声放大 `1/Ts`，外环 10Hz 时尤其严重 |
| 外部速度估计（KF） | 平滑，噪声低 | 有滤波滞后，快速段相位偏差 |

**不要同时叠加两份速度反馈**。本项目早期同时有"PID 内部误差差分 D"和"额外 0.1×KF 速度阻尼"，两者功能重复，等于阻尼被加倍，表现为稳态输出抖动和电机频率噪声翻倍。删掉其中一份后抖动明显下降。

### 3.3 制动包络：把限幅当成控制手段

球接近目标时如果还保持满输出，必然冲过头。制动包络给输出加一个随剩余误差收缩的上限：

```text
env = √(2·K·|e|)

仅当 de/dt < 0（误差正在减小）时：
    u = clamp(u, −env, +env)

env 同时被 brake_min 与 OutMax 夹住
```

物理含义：`√(2K|e|)` 相当于"以恒定减速度 K 刹车，刚好在目标处停住所需的速度上限"。误差大时允许高速，误差小时只允许低速。

调参直觉：

| K 偏小 | K 偏大 |
|---|---|
| 不刹车，过冲大，容易形成大幅极限环 | 近目标时输出不足，推不穿静摩擦，球卡在半路 |

`brake_min` 是包络的下限，防止 `|e|→0` 时输出被夹到完全推不动。包络只在"靠近目标"时生效，球远离目标或已经冲过头时自动放行，不影响回正速度。

### 3.4 Kp 与 Kd 的固有矛盾

纯 P 控制下，稳态误差由"突破静摩擦所需的输出"决定：

```text
e_ss ≈ u_break / Kp
```

- 增大 Kp 能压小残差，但相位裕度下降，振荡幅度成倍增加；
- 增大 Kd 能抑制定点过冲，但大误差段 D 项会超过 P 项，输出方向被翻过来。

实测现象：在中等误差区间（几十毫米），P 项与 D 项符号相反且幅值接近，输出在正负之间来回，形成该区间的持续摆动。这不是参数没调好，而是 PD 结构在该工作点的固有特性。

三种不改 Kp/Kd 的缓解方式：

1. **限制 D 相对 P 的比例**：`|D| ≤ c·|P|`，避免大误差段输出反向；
2. **分段增益**：大误差段用小 Kd，近目标段用大 Kd；
3. **目标速度前馈**：把"目标在动"这件事从反馈里拿出去，减少 D 项负担。

### 3.5 条件积分：只在卡住时积

静摩擦会让纯 P 永远差一截，但常开积分会振荡。折中方案是只在"确实卡住"时累加：

```text
若  输出未饱和
且  数据未过期
且  |e| > 死区
且  低通后的速度 < v_stuck
则  积分偏置 += Ki·e，并限幅到 ±bias_max

若  速度 > v_move
则  积分偏置按 τ 泄放（乘一个小于 1 的系数）
```

要点：

- **速度判据要先低通**：静止时速度估计的噪声可能比慢速爬行还大，直接用瞬时速度会把"运动"误判成"静止"。
- **积分输出挂在包络之外**：包络会把 PID 的 I 项一起夹掉，而这里需要的正是"包络夹不住的常值角度"。
- **限幅限的是积分输出（counts）**，不是累加器。这样"最多能补多少角度"与 Ki 解耦，调 Ki 只改收敛速度。
- **运动时要泄放**：突破静摩擦所需的偏置对动摩擦来说偏大，不泄放就会带着它冲过头。

如果不加泄放、限幅又给得大，会出现**弛张振荡**：偏置慢慢积到突破阈值 → 球突然冲过目标 → 反向回卷很慢 → 几十秒后再来一次。周期长、幅度大，很容易被误判成"机械问题"。

### 3.6 死区：抑制抖动的代价

```text
|e| < deadzone  →  Out = 0，直接返回
```

- 作用：目标附近不再追噪声，电机不抖；
- 代价：**稳态残差的下限就是死区宽度**；
- 死区内的积分必须冻结，否则"带内积偏置、出带冲过头"。
- 死区不是万灵药：目标频繁变化时，每次穿越死区都会产生一个输出台阶。

### 3.7 不对称限幅

受重力分量、摩擦方向、装配偏置影响，系统正负两个方向的能力通常不对称。输出限幅要允许 `OutMax ≠ |OutMin|`。

实测现象：负向先饱和，而正向还有余量；把负向限幅放宽后饱和消失，但 RMS 并未明显改善——说明当时的瓶颈已经从"限幅"转移到"机械能力"。**饱和消失不等于性能提升**，要分开判断。

### 3.8 目标速度前馈

```text
ff = k_ff · (target[k] − target[k−1])
```

- 与 Kd 的实际速度反馈完全独立：目标不动时 `ff=0`，不影响保持模式；
- 前馈只是"提前给角度"，不能突破执行器饱和；
- 前馈符号搞反会让跟踪误差变大，扫描时正负都要试。

## 4. 内环

内环是标准位置式 PID，输入是编码器角度，输出是带符号脉冲频率。

```text
freq = Kp·e + Ki·∫e + Kd·Δe        e = target − actual
```

工程约束：

- **换向安全**：DIR 改变后必须等 ≥1ms 再发脉冲。实现上"换向拍只切 DIR、不发脉冲"，下一拍再升频。
- **频率限幅**：防止超出电机在当前负载下的跟随能力，导致丢步。丢步是开环失控，编码器反馈会突然反向，外环会以为球出了大问题。
- **方向必须一次验证对**：编码器计数方向与频率符号不一致时，内环就是正反馈，电机会单方向跑飞。这是上电第一件要确认的事，不是调参能解决的问题。
- 内环带宽要明显高于外环，否则外环输出的角度指令内环跟不上，串级退化成单环。

## 5. 机械现实

### 5.1 传动回差

法兰联轴器 1:1 直连，实测有 ±30 counts 左右的回差（约 ±2.7°）。

- 表现：稳态时编码器读数在回差区间内抖动，但摆杆实际没有明显运动；
- D 项**修不了回差**，它只会把回差内的编码器噪声当成速度；
- 判断方法：看编码器抖动的峰峰值是否落在回差区间内，同时观察球是否真的在动；
- 影响：稳态残差与极限环的下限被回差抬高。

### 5.2 静摩擦死锁

球不动的条件是驱动力小于最大静摩擦：

```text
m·g·sinθ < F_static
```

于是纯 P 控制出现死锁：

```text
误差 22mm → 输出 44 counts → 杆倾约 4° → 仍推不动
→ 误差不变 → 输出不变 → 永久停在 22mm
```

这不是"增益不够"能解决的问题：继续加 Kp，推得动的那一侧会振荡；加常开积分，会弛张振荡。可行的方向是：

- **位置前馈**：按位置查表补"维持角"，让 P 项只处理残差；
- **条件积分**：只补"卡住"时的常值偏差，运动时泄放；
- **机械改善**：紧固件拧紧、联轴器对中，能显著收窄静摩擦带。

### 5.3 零点只能开环扫出来

- 闭环稳态、速度为零时的编码器读数，只是**静摩擦带内的任意一点**，不是水平零点。
- 同一目标从不同方向进入，稳态读数可以差几十 counts。
- 球在管端时被管壁顶住，"静止"判据失效，只能测到单向起动角。
- 可靠做法：把球放在管中央，开环缓慢增角直到球起动，正反两个方向各测一次，取两个起动角的中点作为水平零点。

### 5.4 加速度上限决定跟踪能力

理想情况下，跟踪振幅 A、角频率 ω 的正弦需要：

```text
a_required = A·ω²
```

±8cm / 4s 对应约 0.2 m/s²。按 `a=(5/7)g·sinθ` 换算，理论上只需要约 1.6° 的倾角。

但实测 4° 左右仍可能推不动球，静摩擦带比理论换算宽得多：**"能产生 0.2 m/s² 的角度"根本推不动球**。要动就得给出远超需求的角度，球动起来后动摩擦更小，又加速过头。于是跟踪过程中杆角大幅往复、输出长期饱和，RMS 降不下去。

这类瓶颈不是调参能突破的。判断方法：

- 看输出饱和占比：长期 >50% 说明已经顶在能力边界；
- 看角度行程：如果编码器已经用满可用行程，再放宽限幅只会更糟；
- 看误差与相位：幅值放大、相位滞后接近 90°，说明闭环在工作频率附近已接近共振。

## 6. 调参方法论

### 6.1 顺序不能乱

1. **方向**：给一个小频率，确认编码器计数与频率同号；不一致先查接线与方向宏，别调 PID。
2. **开环标定**：水平零点、可用角行程、回差峰峰值。
3. **内环**：角度阶跃，调 Kp/Kd，看跟随误差、换向是否丢步。
4. **外环 P**：先只用 Kp，观察收敛与过冲。
5. **制动包络**：从小到大加 K，直到过冲可控且近目标不卡死。
6. **D 项**：换 KF 速度或加误差差分 D，压过冲。
7. **死区**：按可接受的稳态残差设定。
8. **条件积分 / 前馈**：最后处理静摩擦残差与跟踪滞后。

每一步只改一个变量，改完重新采集。

### 6.2 每轮要记录什么

| 场景 | 指标 |
|---|---|
| 定点阶跃 | 过冲、90% 上升时间、进入 ±2mm 的时间、稳态残差、稳态 σ、输出饱和占比 |
| 正弦跟踪 | RMS、最大误差、相位滞后、饱和占比、实际幅值/目标幅值 |
| 滤波对比 | 静止 σ、阶跃附加延迟、尖峰通过率 |
| 数据质量 | 有效帧率、`range_status` 分布、`stale` 次数 |

只看一个指标一定会误判：位置 RMSE 好看可能是滤波滞后换来的；过冲小可能是整体变慢；稳态 σ 小可能是死区把动作全屏蔽了。

### 6.3 哪些数据不可信

出现以下任一情况，当轮数据直接丢弃，不要拿来调参：

- 输出长期饱和（>50%）；
- `stale` 置位或 `range_status` 成片非 0；
- 球在量程边缘或管端被顶住；
- 采集没丢掉启动首周期；
- 运行时间太短。摩擦系统的收敛过程可能长达几十秒，截取前几秒会误判为"不稳定"。

### 6.4 症状 → 根因 → 验证

| 症状 | 可能根因 | 验证方法 |
|---|---|---|
| 单向跑飞 | 编码器方向与频率反了 | 小频率点动，看计数增减 |
| 目标附近小幅高频抖 | D 项噪声 / 回差 / 死区太小 | 断开 D 项看抖动是否消失 |
| 中段大幅往复 | D 项抵消 P 项 | 记录 `ball_out` 与误差符号是否同步反相 |
| 球停在离目标固定距离 | 静摩擦死锁 | 手推一下看是否恢复；看稳态杆角 |
| 几十秒一次的冲过头 | 积分弛张振荡 | 看积分偏置是否锯齿状累积 |
| 越走越偏、最终顶限位 | 丢帧后滤波器外推 | 看 `kf_pos` 是否线性飞走、`stale` 是否置位 |
| 跟踪幅值总比目标大 | 闭环在工作频率附近共振 | 扫频或看相位滞后是否接近 90° |
| 加限幅后指标不变 | 瓶颈已不在限幅 | 看饱和占比是否已经很低 |

### 6.5 反模式

- 在比例项上叠加固定偏移 → 输出全程饱和，退化成 bang-bang；
- 用低频 bang-bang 代替连续控制 → 超调大、容易卡死；
- 用极限环周期反推临界增益 Ku → 幅值撞量程、中心偏离零点时，反推值没有意义；
- 只看位置 RMSE 选滤波参数 → 会选出一个滞后很大的"看起来平滑"的方案；
- 在闭环运行中写 Flash → 擦写会让 CPU 停顿几十毫秒，直接打断控制；
- 用指令角而不是实际角做前馈/滤波输入 → 指令超前一拍，会引入稳态偏差；
- 在输出饱和的状态下继续调增益 → 调的是限幅，不是环路。

## 7. 被推翻的假设

这些问题都曾有过一个"听起来很合理"的解释，最后被实测推翻。记下来是为了少走一遍：

| 曾经的假设 | 实测结论 |
|---|---|
| 稳态偏差是摆杆载荷分布造成的 | 不同位置维持平衡所需力矩基本一致；主因是静摩擦死锁 |
| 偏差来自电机角度与管道角度不一致 | 1:1 直连，角度换算正确；偏差仍存在 |
| 增大 Kp 能把残差压到零 | 残差只小幅下降，振荡成倍增加 |
| 加积分就能消残差 | 常开积分直接引发极限环；只能条件积分 + 泄放 |
| 放宽输出限幅能改善跟踪 | 饱和占比下降但 RMS 不变，瓶颈是机械加速度能力 |
| 滤波参数越低噪声越好 | 要看下游是否使用速度；D 项不用速度时压低噪声是净亏 |
| 短时间数据就能判断收敛 | 摩擦系统收敛可达几十秒，短窗口会误判 |

## 8. 一句话总结

**先让反馈可信，再让内环跟得上，最后才轮得到外环调参。** 如果方向、零点、回差、静摩擦这四件事没搞清楚，任何增益组合都只是碰运气。
