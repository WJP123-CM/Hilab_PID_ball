# 系统架构

> 本文只讲"系统由什么组成、为什么这样分、数据怎么流动"。
> 滤波细节见 [sensing.md](sensing.md)，控制律与调参见 [control.md](control.md)。

## 1. 目标与边界

被控对象是一根可绕一端枢轴倾斜的直管，管内有一个自由滚动的球。控制目标是让球停在管内任意刻度，并跟随缓慢变化的轨迹。

系统边界：

- **单机实时控制**，无操作系统，1ms 定时器节拍 + 前后台主循环。
- **参数不持久化**：增益、目标、滤波参数都由串口下发，掉电即回到代码内默认值。编码器绝对位置与 Flash 存储均未启用——断电后机构会因自重转动，存下来的角度没有意义。
- **不追求通用性**：所有标定（零点、量程、维持角）都针对这一套机械，换管、换球、重新对中后必须重标。

## 2. 硬件与外设映射

| 功能 | 引脚 / 外设 | 关键点 |

| 主控 | STM32F103C8T6 | 72MHz，64KB Flash / 20KB RAM，无 FPU |
| 时钟 | HSE 8MHz → PLL ×9 | SYSCLK 72MHz，APB1 36MHz |

| 电机方向 DIR | PA2 GPIO | 换向后须 ≥1ms 再发脉冲 |
| STEP 脉冲 | PA3 / TIM2_CH4 | PSC=71 → 1MHz 计数时钟，运行期改 ARR |
| 编码器 A/B | PA6 / PA7 / TIM3_CH1/2 | TI12 四倍频，1000 线 → 4000 计数/圈 |
| ToF | I2C1：PB6=SCL，PB7=SDA | VL53L1X，7 位地址 0x29 |
| OLED | I2C2：PB10=SCL，PB11=SDA | SSD1306，128×64，地址 0x3C |

| 上位机 | USART1：PA9=TX，PA10=RX | 115200 8N1 |
| 看门狗 | IWDG | LSI 40kHz / 16，超时约 1.64s |
| 调试 | PA13/PA14 SWD | 三种 openocd 配置：ST-Link / J-Link / DAP-Link |

### 2.1 传动换算

| 量 | 值 | 来源 |
|---|---|---|
| 编码器分辨率 | 4000 counts/圈 | 1000 线 × 4 倍频 |
| 步进分辨率 | 3200 脉冲/圈 | 200 步 × 16 细分 |
| 脉冲/计数比 | 1 脉冲 ≈ 1.25 counts | 4000 / 3200 |
| 角度分辨率 | 0.09°/count | 360° / 4000 |

这两个分辨率是所有角度指令、限幅、回差讨论的单位基础。改细分或改编码器线数，必须同步改宏并重新标定。

## 3. 为什么是串级双环

```text
球位置 ──► 外环(10Hz) ──► 摆杆角度指令 ──► 内环(50Hz) ──► 脉冲频率 ──► 电机
   ▲                        │                 ▲
   │                        └─ 机械传动 ──────┤
   └──────────── ToF ────────────────────────┴── 编码器
```

- **外环**被控对象是"角度 → 球位置"，近似双积分，响应以秒计，用 PD 就够。
- **内环**被控对象是"频率 → 电机角度"，要处理失步、换向、传动回差与静摩擦，必须快。
- 两级之间只传一个量：**摆杆角度指令（编码器计数）**。这样外环完全不必知道电机怎么驱动，内环也不必知道球在哪。

节拍选择：

| 环 | 周期 | 理由 |
|---|---|---|
| 内环 | 20ms（50Hz） | 与 ToF 帧周期同拍，新测距值当拍进入控制；再快没有新反馈可用 |
| 外环 | 100ms（10Hz） | 球动力学慢，10Hz 足够；更快的采样只会放大 D 项噪声，带宽并不会提高 |
| ToF | 20ms（50Hz） | 传感器帧周期；16ms 测量预算 + 4ms 保护 |
| 显示 | 5Hz | I2C 阻塞，不能更快 |
| 遥测 | 50Hz | 与内环同拍，便于观察单拍行为 |

## 4. 软件模块与职责

| 文件 | 职责 | 明确不做什么 |
|---|---|---|
| `main.c` | 初始化、TIM1 调度、外环/内环计算、串口协议、VOFA 帧、OLED 页面 | 不做传感器底层读写 |
| `tof.c` | VL53L1X 驱动、连续测距读帧、`g_tof` 快照、有效帧统计 | 不做控制决策、不发串口帧 |
| `tof_filter.c` | 中值 → EMA → KF 链、位置外推、过期判定、零点与量程门 | 不访问 HAL，纯整数/浮点运算 |
| `kalman.c` | 二维恒速 CV 卡尔曼滤波，通用实现 | 不绑定任何传感器 |
| `pid.c` | 位置式 PID、误差死区、制动包络、外部速度 D 源 | 不持有被控对象状态，只做算术 |
| `motor.c` | TIM2 PWM/DIR/EN、换向安全、频率下发 | 不做位置限幅、不做角度换算 |
| `encoder.c` | TIM3 计数差分累加、方向修正 `g_enc` | 不做速度滤波、不碰 Flash |
| `key.c` | PA0 采样、消抖、事件队列 | 不执行任何业务动作 |
| `oled.c` | SSD1306 显示原语、局部刷新 | 不决定显示内容 |
| `usart.c` | RX 逐字节组行、TX 寄存器直发、RX 自愈 | 不解析命令 |
| 中间件 | VL53L1X 官方 API、SSD1306 驱动 | — |

分层的原则是**一个硬件一个文件**：驱动与它的基本调用放在同一模块，业务输出只出现在应用层。`main.c` 只保留调度与业务，不出现 OLED 点阵操作或 I2C 时序。

## 5. 运行时序

```text
TIM1 1ms 中断
 ├─ tick_ms 自增
 ├─ Key_Tick1ms()                    每 1ms
 ├─ Encoder_Tick()                   每 20ms（先采样，后控制）
 ├─ 外环（10Hz，tick%100）            读 KF → PD/包络 → 内环角度目标
 ├─ 内环（50Hz，tick%20）             读编码器 → PID → Motor_SetTargetFreq
 └─ 置位 tof / cmd / oled / vofa 标志

主循环
 ├─ Tof_Tick()                       阻塞式读帧，最长 2s 超时
 ├─ 串口行解析（10Hz）
 ├─ OLED 刷新（5Hz + 25ms 一页局部回写）
 └─ VOFA 发帧（50Hz）
```

设计约束：

- **阻塞操作全在主循环**：ToF 等待数据、I2C 重试、OLED 刷新都不进中断。
- **控制全在中断**：外环与内环都在 1ms 节拍内按计数值分频执行，保证周期稳定。
- **编码器只采一次**：只在定时器中断里采样，主循环不再调用，避免差分被重复累加。

## 6. 坐标与符号约定

符号错一次，整个环就变成正反馈，所以约定必须只写一处：

| 量 | 定义 | 单位 |
|---|---|---|
| 原始距离 | ToF 输出的球面距离 | mm |
| `pos` | `zero − filt`，**靠近传感器为正** | mm |
| 目标 `target` | 与 `pos` 同向，靠近传感器为正 | 0.1cm |
| 外环输出 `ball_out` | 摆杆角度**增量**指令 | counts |
| 内环目标 `enc_target` | `ball_out + 积分偏置 + 前馈 + ZERO_THETA` | counts |
| 编码器反馈 `enc_actual` | 相对上电位置的累计计数 | counts |

`ZERO_THETA` 是"摆杆水平"对应的编码器读数，由机械装配决定，是所有角度指令的基准。串口目标为正表示球向传感器方向移动，界面与遥测同号。

## 7. 串口协议

### 7.1 参数行（下行）

一行逗号分隔的 1~14 个**整数**，按顺序覆盖参数。省略只能从行尾开始——行中留空会截断该字段及其后的全部字段；写成小数会从该处断开。当前固件不支持字母命令，旧脚本里的 `A`、`Z`、`H1` 在这一版上无效。

```text
Kp,Ki,Kd,brake_gain,brake_min,src,target,bias_max,deadzone,ff_gain,vel_kp,vel_ki,out_max,out_min
```

| 字段 | 单位 | 说明 |
|---|---|---|
| Kp / Kd | — | 外环比例 / 微分增益 |
| Ki | 千分比 | 100 = 0.1；为 0 时同时清积分偏置 |
| brake_gain | — | 制动包络增益，0 = 关闭 |
| brake_min | 千分比 | 500 = 0.5，包络下限 |
| src | 枚举 | 0 = KF 位置，1 = EMA 位置，2 = 速度模式 |
| target | 0.1cm / mm/s | 位置模式为刻度；速度模式为参考速度 |
| bias_max | counts | 积分偏置输出限幅 |
| deadzone | mm | 外环死区，带内输出为 0 |
| ff_gain | 千分比 | 目标速度前馈系数，0 = 关闭 |
| vel_kp / vel_ki | counts/(mm/s) / 千分比 | 速度模式增益 |
| out_max / out_min | counts | 外环输出上下限，允许不对称 |

全部用整数解析，是为了避免把 `strtof` 和浮点格式化库拉进只有 64KB Flash 的片子。

### 7.2 遥测帧（上行）

50Hz，VOFA FireWater 文本帧，11 个整数通道：

| 通道 | 名称 | 单位 | 用途 |
|---|---|---|---|
| 0 | `enc_target` | counts | 内环目标角度 |
| 1 | `enc_actual` | counts | 编码器角度反馈 |
| 2 | `enc_out_hz` | Hz | 内环输出频率（带符号） |
| 3 | `ball_target` | 0.1cm | 外环目标 |
| 4 | `raw_mm` | mm | 原始测距（已换成"靠近为正"） |
| 5 | `ema_mm` | mm | EMA 链输出（对照） |
| 6 | `kf_pos` | mm | 卡尔曼位置估计 |
| 7 | `kf_vel` | mm/s | 卡尔曼速度估计 |
| 8 | `kf_state` | 位域 | bit0 = 持续背离告警；bit1~4 = 背离计数；bit5~7 = 丢帧计数 |
| 9 | `ball_out` | counts | 外环输出（不含偏置与前馈） |
| 10 | `range_status` | 码 | 0 有效；>0 为传感器状态；−1 超时；−2 读失败；−3 越量程门 |

**帧里不允许出现任何调试文本**。错误状态用数值通道承载，否则 FireWater 解析会被打断。

## 8. 资源与实时性约束

- **Flash 余量有限**：新增模块先看 `arm-none-eabi-size`，Debug 与 Release 差距很大，比较时注明构建类型。
- **20ms 主循环预算**：ToF 读帧本身就占十几毫秒，任何新的阻塞操作都会把遥测周期拉长。
- **IWDG 1.64s**：初始化阶段每一步都要喂狗；喂狗周期必须留出 200ms 以上余量。
- **无 FPU**：浮点都是软件模拟，50Hz 下开销可忽略，但不要在高频中断里堆浮点运算。
- **newlib-nano 不支持 `%f`**：所有打印与遥测只用整数。
