# 测距与信号链

> 单点激光 ToF 测一个曲面滚动体，得到的不是"球心坐标"，而是一串带状态码、带量程边界、会漂移的距离值。
> 本文记录这条信号链是怎么一步步变成可用位置反馈的。

## 1. 单点 ToF 不能直接当位置传感器

| 现象 | 原因 | 后果 |
|---|---|---|
| 读数随球的位置轻微非线性 | 测的是球面**最近点**，不是球心；光轴与球心不在一条线上时，最近点会游移 | 绝对刻度必须逐点标定，不能按几何直接换算 |
| 回波强度随距离快速下降 | 漫反射回波约按 1/d² 衰减 | 量程由回波率阈值决定，不是数据手册上的标称值 |
| 换球后噪声完全变了 | 钢珠是曲面镜面，反射方向集中；POM 白球是漫反射 | 钢珠回波弱、噪声大，已弃用 |
| 偶尔出现很大的孤立跳变 | 弱回波、多路径、环境光 | 单帧不可信，必须做时间域滤波 |
| 每次上电零点和稳态误差会变 | 模块内部偏移与安装应力 | 绝对距离不能写死，只能每次重新锚定 |

结论：单点 ToF 可以做出毫米级的位置反馈，但前提是**把它当成一个需要标定、需要有效性判定的传感器**，而不是一把尺子。

## 2. 数据有效性要分四层判断

同一条测距结果可能因为四种完全不同的原因不可用，必须分开表达，否则现场无法定位：

| 层 | 判据 | 标记 | 含义 |
|---|---|---|---|
| 通信 | I2C 超时 / 读失败 | −1 / −2 | 总线或传感器没响应 |
| 传感器状态 | `range_status != 0` | 原样透传 | 1 sigma 超限、2 信号弱、5 硬件失败、7 绕回失败等 |
| 工程量程 | 超出 `[min_valid, max_valid]` | −3 | 通信正常、状态正常，但距离不在可用区间 |
| 时间有效性 | 距最后一帧有效数据超过 200ms | `stale` | 数据链断了，当前值只是历史值 |

只有四层全部通过，这一帧才允许进入滤波与控制。业务层不应该自己拼这些判断——判定必须收在滤波器内部，控制层只读"是否 stale"。

## 3. 量程是标定出来的

传感器有一个最小回波率阈值，低于它就把结果判为绕回失败（status 7）。设阈值为 τ，则有效边界大致满足：

```text
d(τ) ≈ d₀ · √(τ₀ / τ)        （回波 ∝ 1/d²）
```

本机实测锚点：阈值 1.5 MCPS 时边界约 360mm；阈值放宽到 0.9 MCPS 后理论边界约 465mm，实测 400~479mm 段有效帧 100%。

放宽阈值不是免费的：

- 远端的弱回波会被当成有效帧，噪声与尖峰比例上升；
- 光路里出现固定反射物时，更容易"锁"在错误距离上；
- 阈值过低会把量程推到远超需求的位置，收益为零、风险变大。

**做法**：先确定真正需要的最大距离，再留 5%~10% 余量反推阈值，不要用"传感器能测多远"当调参目标。

## 4. 滤波链

### 4.1 中值：先剔除孤立尖峰

VL53L1X 在 `status=0` 的情况下也会给出 ±20~35mm 的单帧跳变。中值滤波对"单帧离群"最有效：

- 窗口 N=3 可剔除单帧尖峰，群延迟 1 帧（50Hz 下 20ms）；
- 群延迟约为 `(N−1)/2` 帧，N 越大越平滑、滞后越大；
- 中值不改变阶跃的稳态值，只削掉毛刺。

### 4.2 EMA：平滑随机噪声，但会拖慢

```text
y[k] = α·z[k] + (1−α)·y[k−1]
τ ≈ −Ts / ln(1−α)
```

α 越大越跟手、噪声抑制越弱。时间常数与系数、采样周期都有关，换采样率必须重新换算，不能只改 α。

本工程里 EMA 只作为**并行对照与故障兜底观测**，输出始终取卡尔曼。原因：自动回退只会在传感器盲区触发，而盲区里两条链都不准；来回切换还会把滤波器状态拖到陈旧值。

### 4.3 卡尔曼：给位置和速度一个统一估计

采用二维恒速（CV）模型，状态 `x = [位置, 速度]ᵀ`：

```text
预测：
  x⁻ = F·x,        F = [1  dt]
                       [0   1]
  P⁻ = F·P·Fᵀ + Q

  Q = σa² · [dt³/3  dt²/2]
            [dt²/2  dt   ]

更新（位置观测 H = [1, 0]）：
  S = H·P⁻·Hᵀ + R
  K = P⁻·Hᵀ / S
  x = x⁻ + K·(z − H·x⁻)
  P = (I − K·H)·P⁻
```

几个实用结论：

- **Q 用单参数 σa² 生成**，换采样周期不必重调整套矩阵。交叉项 `q01` 不能省——纯对角 Q 会让速度估计滞后于真实运动。
- **参数判据**：令每拍位置方差增量 `q00 ≈ R`，稳态增益约 0.5~0.6，等效 EMA α≈0.55。这是"噪声与跟手"比较平衡的起点。
- **σa² 的取值取决于下游怎么用**：如果 D 项用位置差分，滤波器速度噪声不会进环路，可以把 σa² 压得很低只求平滑；如果 D 项直接用 KF 速度（本项目），就必须优先压速度噪声，代价是快速段速度滞后增加。
- **滤波器参数没有"绝对最优"**，只有"对某个下游用法最优"。

### 4.4 新息门控不是万能的

常见的 5σ 门控写法：

```text
若 innov² > n²·S，则本帧观测判为离群并丢弃
```

它削尖峰很有效，但在快速运动时会**锁死**：球每拍位移超过门限，所有真实观测都被拒绝，滤波器只能靠预测外推。本工程最终没有启用门控，尖峰交给中值和状态/量程门处理。

如果要用门控，必须配套"连续越限自动放行"，否则真实阶跃会被当成异常。

### 4.5 外推：补采样滞后，但要有边界

测距帧间隔约 20~34ms，控制比它快，直接用上一帧位置会引入固定滞后。用速度估计外推：

```text
pos(t) = pos_k + v_k · Δt
```

外推必须同时限制三件事，否则丢帧时会把电机顶到限位：

| 限制 | 作用 |
|---|---|
| Δt ≤ 1.5 个帧周期 | 不允许把一次丢帧外推成几十毫秒 |
| 单次外推位移 ≤ 20mm | 速度估计再大也不会让位置跳变 |
| 低速不外推、高速才全量外推 | 静止时避免把速度噪声放大成位置抖动 |

### 4.6 数据过期必须冻结

连续无有效帧时，卡尔曼会按最后一次速度**无限外推**。位置会一路飞走，外环输出饱和，电机持续顶住限位——这不是理论风险，是实测踩过的坑。

处理方式：

- 超过 200ms 没有有效帧 → 置 `stale`，停止预测，输出冻结在最后一次有效值；
- 外环检测到 `stale` 后停止积分（P/D 因位置冻结自然保持）；
- 恢复有效帧时，用**当前真实测距值**重新播种滤波器，而不是沿用旧状态。

这个判定必须封装在滤波器内部，业务层不要自己拿时间戳算。

## 5. 零点、刻度与换装

- **绝对距离会漂**：同一位置重新上电，读数可能差几毫米。零点必须能在线重标，不能写成常量。
- **闭环稳态读数不是真零点**：球停在目标附近时，杆角在静摩擦带内任意取值，对应的测距值也只是带内随机点。
- **换球、换管、重新对中、紧固件力矩变化 → 所有绝对距离与刻度数据作废**。旧数据只能做定性对比，不能混算指标。
- 真实水平零点只能通过开环双向起动扫描获得，方法见 [control.md](control.md) 的"静摩擦与零点"一节。

## 6. 硬件层：EMI 与 I2C

电机驱动板上电后，即使电机不转，也会通过电源与地线干扰 I2C：

- 现象：测距频繁超时、SDA 被拉死、初始化卡住触发看门狗复位；
- 软件能做的是"止血"：检测到卡死后 DeInit → SCL 打 9 个时钟 → STOP → 重新初始化；
- 根因处理在硬件：逻辑电源与电机电源分开、缩短排线、双绞或屏蔽、必要时加磁珠、确认上拉电阻（4.7kΩ）。

其他硬件约束：

- ROI 的 y 轴是反向的：`TopLeftY ≥ BotRightY`；
- 测量预算必须 ≤ 帧周期 − 4ms，否则启动测量直接返回错误；
- 读帧是阻塞等待，最长 2s 超时，**只能放主循环**。

## 7. 经验卡片

| 现象 | 根因 | 怎么判断 | 处理 |
|---|---|---|---|
| 单帧剧烈跳变但状态正常 | 弱回波 / 多路径 | 看相邻帧差值是否超过物理速度极限 | 中值预筛；必要时门控 |
| 越远越不准、最后直接没数据 | 回波率低于阈值 | 看 `range_status` 是否成片为 7 | 按需求边界重设阈值，别贪量程 |
| 标定好的零点第二天变了 | 模块稳态误差漂移 | 同一物理位置重新上电读数不同 | 每次测试前用已知位置重锚 |
| 丢帧后电机顶住限位不动 | 卡尔曼按最后速度无限外推 | 看 `kf_pos` 是否线性飞走、`stale` 是否未置位 | 数据过期冻结 + 恢复重播种 |
| 静止很稳，一动就滞后 | 滤波过度平滑 | 对比静止 σ 与阶跃 90% 上升时间 | 降低平滑强度，或让 D 项取更快的信号源 |
| 换球后所有指标都变差 | 目标材质/曲率变了 | 回波率与噪声统计 | 重新标定量程、零点与滤波参数 |

## 8. 三条原则

1. **先判有效，再谈精度**：状态码、量程、时间有效性任何一条不过，数据就不该进控制。
2. **滤波器参数跟着下游走**：同一个滤波器，给显示看和给 D 项用，最优参数完全不同。
3. **没有失效保护的估计器不能用**：任何会外推的滤波器，都必须有数据过期冻结。
